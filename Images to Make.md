# Taipei Walkabout: images to make in ChatGPT

This is every picture the game is still missing, in order of how much each one improves the game. Each one has a ready-to-paste prompt and the exact file name to save it as.

**How to use this**
1. In ChatGPT, paste one prompt at a time. For a character, paste the prompt **and** the style line for that section.
2. Download the image and rename it to the file name shown (lower-case, exactly as written).
3. Send me the images (attach them in this chat) and I'll add them to the game and update the website. You can also drop them straight into the game's `art` folder, and the game picks them up automatically. ChatGPT downloads PNG files, so if you add a `.jpg` picture yourself, convert it first. Or just send it to me and I'll convert it.

Until a picture exists the game keeps working: it uses a real photo, a blurred street view or a placeholder.

**ChatGPT sizes:** ChatGPT makes portrait 1024 × 1536, landscape 1536 × 1024 or square 1024 × 1024. Use **portrait** for characters and **landscape** for everything else. If ChatGPT gives you a different size, that's fine.

**Tip for a consistent cast:** make a character's `_neutral` picture first. Then, in the **same chat**, say *"Same character, same outfit, same style. Now make the happy version: …"* and then the surprised version. That keeps the face and clothes identical across all three.
